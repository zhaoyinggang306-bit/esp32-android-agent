# ESP32 Android Agent

Android app for the ESP32 USB-HID control path. It uses BLE to command the board, and Android's consent-gated MediaProjection API for local screen frames.

See [the hardware guide](../docs/android.md) for setup and safety constraints.

Based on [ESP32 iPhone Agent](https://github.com/onehumanbeing/esp32-iphone-agent) by Henry Yuan. Copyright (c) 2026 Henry Yuan; the repository-level MIT `LICENSE` and `NOTICE` apply.
