# ESP32 控制安卓：实操步骤（Windows / D 盘）

本方案让 **ESP32-S3 插在同一部安卓手机上**，模拟 USB 鼠标、键盘和 Home 键。Android App 通过蓝牙给板子下命令；手机屏幕由系统 MediaProjection 授权给 App 读取。它不是 ADB 方案，不需要打开 USB 调试。

> 仅控制自己拥有或已获授权的设备和账号。屏幕读取会出现 Android 的系统授权弹窗和常驻通知；不要绕过它。

## 1. 已安装的软件与目录

| 用途 | 位置 |
|---|---|
| JDK 17 | `D:\Android\jdk17` |
| Android SDK（API 35、Build Tools 35） | `D:\Android\sdk` |
| Gradle 8 | `D:\Android\gradle-8.0` |
| Arduino CLI | `D:\Arduino\CLI\arduino-cli.exe` |
| Arduino 数据、板卡与库 | `D:\Arduino\data`、`D:\Arduino\sketchbook` |
| Arduino 配置 | `D:\Arduino\arduino-cli.yaml` |
| Android Studio | `D:\Android\Android Studio`（安装完成后） |

当前用户环境变量 `JAVA_HOME`、`ANDROID_HOME` 与 `ANDROID_SDK_ROOT` 已指向上述 D 盘目录。新开一个 PowerShell 窗口后生效。

## 2. 准备硬件

1. 使用原生 USB 的 ESP32-S3，推荐 XIAO ESP32S3（普通 8 MB PSRAM 版）。
2. 准备一根支持数据与 OTG 的 USB-C 线；不要用只充电线。
3. 安卓手机需要支持 OTG 主机模式。部分小米/OPPO/三星机型需在“设置 → OTG”中先打开，通常会在一段时间后自动关闭。
4. 首次刷写时，**板子接电脑**；日常控制时，**板子接安卓手机**。

## 3. 等待 ESP32 Core 下载完成并安装库

ESP32 Core 约 378 MB，后台下载期间可用以下命令检查：

```powershell
Get-Process arduino-cli -ErrorAction SilentlyContinue
D:\Arduino\CLI\arduino-cli.exe core list --config-file D:\Arduino\arduino-cli.yaml
```

出现 `esp32:esp32 3.3.7` 后，执行：

```powershell
D:\Arduino\CLI\arduino-cli.exe lib install "NimBLE-Arduino@2.5.1" --config-file D:\Arduino\arduino-cli.yaml
```

## 4. 编译并刷写 ESP32

1. 将板子接到电脑，打开 PowerShell，查看串口：

```powershell
D:\Arduino\CLI\arduino-cli.exe board list --config-file D:\Arduino\arduino-cli.yaml
```

记下输出中的 `COMx`。如果没有出现，长按板子 Boot 键，再短按 Reset 键，然后松开 Boot 键。

2. 在项目根目录编译。这个 FQBN 适合 8 MB、OPI PSRAM 的 XIAO ESP32S3；若你的板子不同，请按实际 Flash/PSRAM 改配置：

```powershell
cd D:\企业微信\esp32-android-agent
$cli = 'D:\Arduino\CLI\arduino-cli.exe'
$cfg = 'D:\Arduino\arduino-cli.yaml'
$fqbn = 'esp32:esp32:esp32s3:USBMode=default,CDCOnBoot=cdc,FlashSize=8M,PSRAM=opi,PartitionScheme=default_8MB'
& $cli compile --fqbn $fqbn --config-file $cfg --output-dir .\hardware\android_hid_bridge\build .\hardware\android_hid_bridge
& $cli upload --fqbn $fqbn --config-file $cfg --port COMx --input-dir .\hardware\android_hid_bridge\build
```

成功后，板子会广播蓝牙名称 **`ESP32 Android Agent`**，并在 USB 连接时枚举为鼠标和键盘。

## 5. 构建和安装 Android App

1. 打开 Android Studio，选择 **Open**，选择 `D:\企业微信\esp32-android-agent\android`。
2. 第一次打开时接受 Gradle 同步；SDK Location 应为 `D:\Android\sdk`。若提示缺少 SDK，选择 Android API 35 和 Build Tools 35.0.0。
3. 通过 USB 连接手机到电脑，开启“开发者选项 → USB 调试”，用于**安装 App**（日常控制不需要 USB 调试）。
4. 在 Android Studio 选择该手机并点击 Run，或新开 PowerShell 执行：

```powershell
cd D:\企业微信\esp32-android-agent\android
$env:JAVA_HOME = 'D:\Android\jdk17'
$env:ANDROID_HOME = 'D:\Android\sdk'
$env:ANDROID_SDK_ROOT = $env:ANDROID_HOME
D:\Android\gradle-8.0\bin\gradle.bat :app:assembleDebug
D:\Android\sdk\platform-tools\adb.exe install -r .\app\build\outputs\apk\debug\app-debug.apk
```

## 6. 首次连通测试

1. 断开手机与电脑的连接，将已刷写的 ESP32-S3 用 OTG 数据线插入安卓手机。
2. 如系统询问 USB 设备权限，允许；应该能看到鼠标指针或“物理键盘”提示。
3. 打开 **ESP32 Android Agent** App，允许“附近设备”蓝牙权限。
4. 点 **连接 ESP32**，状态应显示“已连接；USB 插入手机后可发送 HID 动作”。
5. 点 **测试点击**：如果屏幕当前有可点击控件，ESP32 将以物理鼠标点击当前位置。
6. 点 **返回桌面**：应回到桌面。若无反应，先在手机设置确认 OTG 已启用，并换一根数据线。
7. 点 **授权屏幕读取**，在系统弹窗确认。App 会显示“正在读取屏幕以执行你的任务”的常驻通知；这是正常的安全提示。

## 7. 常见问题

- **App 找不到 ESP32**：先拔插板子，关闭并重新打开手机蓝牙；板子应广播 `ESP32 Android Agent`。
- **能连蓝牙但不能点击**：这是 USB OTG、数据线或供电问题，不是蓝牙问题。确认手机支持 OTG，换数据线，并检查设置中的 OTG 开关。
- **刷写找不到 COM 口**：按住 Boot 后按一下 Reset 进入下载模式，再运行 `board list`。
- **Gradle 提示 Java 不存在**：关闭并新开 PowerShell；或在当前窗口设置 `$env:JAVA_HOME = 'D:\Android\jdk17'`。
- **屏幕授权后没有画面**：部分银行、DRM 视频与安全界面会被 Android 故意保护，MediaProjection 无法读取；这是系统限制。
